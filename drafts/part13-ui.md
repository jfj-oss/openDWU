## PART 13 — USER INTERFACE (complete specification)

### 13.1 Main menu
Buttons: **Tutorials** (11 selectable: basic, advanced, Dealing With Pirates, Empire and Colonies, Expansion and Diplomacy, Finding Your Way Around, Fleets and Troops, Play as Pirate, Pre-Warp Empire, Research and Design, Ships and Missions), **Start New Game**, **Quick Start** (14 presets: Random, Fast, Epic, Ring Race, Conflict, Expanding Settlements, Expanding from the Core, Fully Developed Small/Standard/Large, Galactic Republic – Supreme Ruler, Galactic Republic – Wild Frontiers, Sovereign Territories – Regional Ruler, Sovereign Territories – Minor Faction), **Load Game**, **Galactopedia** (the in-game help encyclopedia — all ~309 topics, context-sensitive via F1), **Options** (Display, Sound, Auto Saves, Mouse Scroll-Wheel Behaviour, Automation, Empire Settings, Messages, Change Theme, Credits, Exit), **Exit**. Credits scroll along the right side. A theme-switcher screen lists all folders in Customization/ with a summary preview of the selected theme and a "Change Theme" button (applies immediately to a running game's presentation).

**Start New Game wizard (custom game)** — step by step:
1. **Era and empire type**: Classic Era (planetary empire, original storyline), Age of Shadows (planetary, pre-hyperspace option), Ancient Galaxy (storyline with custom theme/map), Play as Pirate (Shadows or Classic-era pirates), or fully **Custom Game** (Standard Empire or Pirate Faction) with full control over every setting below.
2. **Galaxy customization**: galaxy size (stars: e.g. 70 to 1,400+ — presets Small/Medium/Large/Custom; sector grid size, default 10x10), galaxy **shape** (6 options: Elliptical, Spiral, Ring, Irregular, Even Clusters, Varied Clusters), **difficulty** (comprehensive AI-improvement setting; optional difficulty scaling as player nears victory; option to prevent destroyed pirates being replaced), prevalence of habitable/colonizable planets, prevalence of independent alien life, prevalence of pirates, research speed, **aggression** level of other empires, resources per planet, resources per system, resource types enabled, nebulae on/off, colony influence range, colonization range limits, storyline toggles (Off / partial / full; Shakturi storyline; Ancient Galaxy; Shadows events; Disasters; Events; special victory conditions).
3. **Player race**: choose from the 22 playable races (plus pirate races for pirate games; certain pirate playstyles unavailable to some races). For pirates, choose the primary race (affects bonuses/tech) and the **playstyle** (Balanced, Mercenary, Raider, Smuggler — playstyle cannot be changed in-game and defines pirate victory conditions).
4. **Player empire customization**: name, flag (shape from 39 designs + primary/secondary colors from 20/21 palette), race, starting size and age (empire "growth stage" — e.g. tiny/medium/large affects starting colonies and tech), starting location, home system harshness/fecundity, government type, corruption level, starting technology level.
5. **Opponents**: number of AI empires, and for each: name (or automated), race, size, government, proximity to player, technology level; or fully automated creation.
6. **Victory conditions**: choose criteria (territory %, population %, economy/strategic-value %, race-specific, pirate playstyle, time limit) and the dominance threshold; optional "victory only after time T"; storyline alternate-victory toggles.

### 13.2 Main View (the map screen)
- **Zoom levels**: 100% (planets/ship sprites visible) → system overview → sector grid → full galaxy. Mouse wheel zoom (option: none / center-on-selection / center-on-cursor); Page Down zoom in, Page Up zoom out; Home = 100%, Insert = system level, Delete = sector level, End = galaxy level.
- **Panning**: mouse-at-edge scroll, right-button drag, arrow keys. Ctrl-left-click centers view on clicked location at 100%. Backspace zooms to selected item. L locks/unlocks view on selected item.
- **Selection**: left-click selects (pop-up list if several objects at one spot); shift-click multi-selects in lists; hover shows a summary readout in the lower-middle; the **Selection Panel** (bottom-left) shows detailed info for the selected item with forward/back selection-history buttons (N/B keys), drill-down links (double-click ship name → ship detail screen; click base design name → design screen), and a resize handle.
- **Right-click**: pop-up context menu with all missions/appropriate actions for the selected item (holding Ctrl right-clicks forces the full mission list; cursor shape indicates the default mission: red targeting cursor = attack, etc.). If nothing is selected, right-click centers the view on the cursor.
- **Top bar**: Game menu (Esc) + Galactopedia (F1) buttons; Pause (Space) and speed +/– buttons; current star date; cash on hand + cash flow + annual bonus income (top-right); name of the system currently in view; **scrolling message list** (5 most recent messages; clicking a message jumps to the event location or opens the relevant screen).
- **Screen launch buttons** (below the message list): Colonies (F2), Expansion Planner (F3), Empire Comparison & Victory (V), Empire Policies, Game Editor, Characters (F4), Diplomacy (F5), Empire Summary (F6), Research (F7), Ship & Base Designs (F8), Build Order (F9), Construction Yards (F10), Ships and Bases (F11), Fleets (F12), Troops, Galaxy Map (G), Message History (H).
- **Empire Navigation Tool** (left side): scrollable lists, each toggled by icon: Colonies, Characters, Spaceports and Construction Yards, Mining stations, Construction ships, Exploration ships, **Enemy Targets**, Fleets, Military ships, **Pirate missions**, Potential colonies, Potential mining stations, Potential Research locations, Potential Resort locations, Special locations. Hover pings an item's location on the galaxy map (expanding yellow circle); click selects it in the Selection Panel; double-click moves the main view; shift-click multi-selects (e.g. form a fleet via the Create New Fleet action button). **Enemy Targets list**: shows all known enemy targets; clicking assigns your nearest available fleet (or your selected fleet) to attack it; right-click cancels an assigned attack.
- **Action buttons** (under the Selection Panel): context-specific commands for the selected object — e.g. ships: Refuel, Repair, Retrofit, Retire, Scrap, Automate (A), Stop (S), Escape (E), Create New Fleet, Load/Unload Troops, Manage Fighters/Bombers; colonies: Recruit Troops, Build, Set Tax; plus per-list actions (Colonize, Build Station, etc.).
- **Minimap** (bottom-right): shows the surrounding area at the current zoom (planets/moons in system view; stars/nebulae in galaxy view); viewport rectangle; click to move view. Overlay toggle buttons along its top, in order: **Fade Civilian Ships and Bases**, **Fleet Postures**, **Travel Vectors (State ships)**, **Travel Vectors (Private ships)**, **Potential Colonies**, **Scenic Locations**, **Potential Research Locations**, **Long Range Scanner coverage**, **Sphere of Empire Influence**.
- **Map rendering**: colonies display name badges (name at top; gold star for capital; resource icons bottom-right; dominant race + population-size/development graph bottom-left); ships render as sprites with empire-colored ship-type symbols (solid outline = state-controlled, dashed = private); bases similar; nebulosity as colored cloud overlays; resource symbols; system influence circles; travel vectors as lines; fleet posture coloring.

### 13.3 Message system
Three message channels: (1) **Pop-up messages** (require attention; slide in at right; suppressible in options for unattended play), (2) **Diplomacy/Advisor messages** (stacked list at right of screen), (3) **Scrolling messages** (top bar). All are stored in the **Message History** screen (H): list of past messages, body text, related-location mini-map with a "jump to location" button, optional "Show Battle messages" checkbox. Messages that reveal previously unknown locations show a dashed blue "ping" circle in galaxy view until explored. Options let the player enable/disable each of the ~12 event categories for popups and scrolling messages separately.

### 13.4 Screens (complete inventory)
- **F1 Galactopedia** — full encyclopedia (all topics listed in Content section); context-sensitive index.
- **F2 Colonies** — list of colonies with stats; rename colony; per-colony tax rate slider (0-40%); tabs: Population (demographics per race, attitudes), Cargo, Resources (current stock + shortages), Troops (recruit/disband, garrison), Construction Yard (build queue), Docking Bay (docked ships).
- **F3 Expansion Planner** — top: galaxy-wide resource supply/demand table (current supply, unfulfilled demand, in transit) per resource; middle: list of potential targets (dropdown filter: potential colonies / potential mining / etc., sortable columns, resource filters, color-coded warnings for colonized systems / pirate danger / low quality); bottom: dropdown of available colony ships or construction ships + buttons to queue Colonize or Build missions; right: galaxy map with target location + "Select in Main View"/"Move to" buttons.
- **F4 Characters** — list of all characters (type, skills, traits, experience, assignment); detail panel per character; buttons: assign to homeworld/colony/spaceport/research station/fleet/planet/ship, dismiss; **intelligence agent missions**: select agent → cancel current mission → target empire → mission type (12 types, see Diplomacy section) → optional specific target → time allowed → "Assign Mission" (shows estimated success probability; >85% recommended).
- **F5 Diplomacy** — left: list of all known empires (player at top; pirate factions included); relationship web (colored lines per relation type with legend at right); per-pair annual trade volume + treaty bonus display; right: Empire Summary panel (flag, name, dominant race + traits, other races, government, colony count, reputation, military strength, current relationship + influencing factors); **"Speak" button** opens the conversation dialog (see Diplomacy section).
- **F6 Your Empire Summary** — empire name (editable), Colony Information panel (summary + current government's bonuses/handicaps + dropdown to change government → "Have Revolution" button with warnings), State & Private economy panels (all income/expense lines: taxes by size class, state port income (construction + fees), trade fees, free-trade/Mutual Defense bonus income, tourism income; expenses: ship maintenance (military/civilian split), base maintenance, troop maintenance, agent maintenance; cash flow, reserves), Ships and Bases summary (all ships/bases: location, design, firepower, maintenance; multi-select commands: Refuel/Repair/Retrofit/Retire/Scrap), government change, "Set Empire Policy & Automation" button opening the Empire Policy screen.
- **F7 Research** — three tabs (Weapons / Energy / HighTech) each showing the full tech tree: nodes arranged by tech level (columns 0-8) and row; queued projects shown; click to queue, right-click to cancel (queue re-orders); red prerequisite lines; hover shows details (prerequisites, unlocked components/improvements/abilities/facilities/fighters); race-limited projects shown as locked; tab for **Research Stations list** (per-station output in the 3 areas, "Go to" button); bottom: Total Empire Research Potential, Total Research Capacity, Actual Output (red background) with racial/government/character/location/ruins bonuses listed; **crash research** (lightning-bolt icon; 3x speed for a money cost, applied to the first queued project).
- **F8 Ship Designs** — list of all designs (ships and bases); design detail: component list with per-component stats and damage states; the **design editor** for creating new designs: choose design type (one of 31 roles), size/hull budget, add/remove/upgrade components (only researched ones), auto-added components (command center, life support, habitation modules, hyperdrive on ships, sufficient reactors/energy collectors), validation rules (min/max component rules per specification); image scaling mode; race design templates as starting points.
- **F9 Build Order** — construction queue management: list of ships being built at each yard, reorder/pause/cancel.
- **F10 Construction Yards** — list of all yards (planetary, space-port, on construction ships) with current build queues, build points, completion times, crewed status.
- **F11 Ships and Bases** — central list of every ship and base (state + private), location, mission, fleet, status; multi-select (drag/ctrl/shift) and bulk commands; per-ship detail (components, damage, cargo, fuel, shields, weapons, troops, automation state).
- **F12 Fleets** — list of fleets (name, leader, member ships, posture, mission, location); create/rename/dissolve; set fleet posture (attack/defend/neutral), battle tactics, default engagement range, default flee-when, default loadout of troops; assign admirals.
- **Troops screen** — list of troop units (name, type, size/strength/readiness, location, garrisoned?); multi-select; Recruit/Disband/Garrison/Ungarrison buttons; total maintenance cost; galaxy map of selected troop location; per-colony troop recruiting also available from the colony screen and right-click menu.
- **V Empire Comparison & Victory Conditions** — graphs comparing the player vs all known empires in population, territory, economy, strategic value, military strength; "Top Colonies" tab (top 10 by strategic value); victory condition status (nearest empire, how total victory level is computed); **Victory and Achievements** tab: progress in achievement categories, medals/achievements for the player and other factions; completed games' results and achievements are stored permanently.
- **O Game Options** — all option groups from the main menu (display: scroll/zoom speed, star density, advanced: max FPS, nebula detail; sound: music/SFX volumes; autosave interval 10-30+ min and pause-on-load; scroll-wheel behaviour; automation per-domain; empire settings; message categories; theme switcher).
- **G Galaxy Map** — grid of sectors (light blue boundaries); view filter; galaxy map with selection crosshairs; system map (planets/moons/asteroids of selected system); selection summary (system summary: planet/moon counts, owner per planet, known resource list with hover/click details, colonized planets & mining stations visual with owner/race); surface image of the selected planetary surface.
- **H Message History** — as described in 13.3.
- **Game menu (Esc)**: Exit, Exit to Main Menu, Load Game, Save, Save As, Game Options, Game Editor, Cancel.
- **Game Editor** — left panel: place tools (empires/colonies per-empire dropdown, ships, bases, planets, stars, nebulae, ruins, resources, creatures, characters, plagues) and erase tools (per object type); left-click places, double-click any object opens the right-side Edit panel (all properties editable; changes apply on click-away); "Edit Empires" button lists all empires for detail editing (details, colonies, research, ships and bases); "Exit Editor" returns to the game (then save). Event/scenario editor: define triggers (object conditions/events) → action lists (immediate or delayed, targeting other objects), scenario objectives and results.

### 13.6 Mouse actions
Left-click: select (pop-up chooser if ambiguous). Left-drag: box multi-select in lists. Right-click: context mission menu / default mission (hover-dependent default with cursor feedback); Ctrl+right-click: forced full mission list. Right-drag (right button held): pan. Scroll wheel: zoom (per option). Hover: summary readout; in navigation lists: location ping; in tech tree: project details. Shift-click / Ctrl-click: multi-select / toggle in lists.
