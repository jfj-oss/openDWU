# Dwureup

Research and implementation plan for recreating *Distant Worlds: Universe*, produced in the DeepSeek harness workspace.

- [`Distant_Worlds_Universe_Recreation_Prompt.md`](Distant_Worlds_Universe_Recreation_Prompt.md): the full specification covering rules, formulas, data tables, UI, data formats, assets, and the staged implementation plan with acceptance criteria (Part 15).
- [`drafts/`](drafts/): per-part drafts and content tables (races, governments, components, facilities, research tree, and more) that were compiled into the spec.
- [`distant-worlds/ROADMAP.md`](distant-worlds/ROADMAP.md): implementation roadmap.
- [`distant-worlds/data/FORMAT.md`](distant-worlds/data/FORMAT.md): data file format reference.
- [`dwu-research/sections/`](dwu-research/sections/): UI research (`06-ui.md`) and the working extracts it was built from (`_work/`).

The implementation lives in [jfj-oss/GAMEDW](https://github.com/jfj-oss/GAMEDW).
