openDWU needs your Distant Worlds: Universe files

openDWU is a recreation of Distant Worlds: Universe. It ships none of the original game's art, sounds or data: it reads them from your own copy of the game. Choose the folder where Distant Worlds: Universe is installed, the one that contains the images folder and races.txt.

Where to find it

  • Steam installs it to C:\Program Files (x86)\Steam\steamapps\common\Distant Worlds Universe, or <drive>:\SteamLibrary\steamapps\common\Distant Worlds Universe for another library.
  • In Steam: right-click Distant Worlds: Universe → Manage → Browse local files opens the folder; copy its path from the Explorer address bar.
  • Steam installs it to ~/.local/share/Steam/steamapps/common/Distant Worlds Universe (Flatpak Steam: ~/.var/app/com.valvesoftware.Steam/.local/share/Steam/steamapps/common/Distant Worlds Universe).
  • In Steam: right-click Distant Worlds: Universe → Manage → Browse local files opens the folder. The game does not have to run under Proton; only its files are read.

Distant Worlds: Universe is a Windows game, so a Mac has no native install. openDWU only needs the game's files, not a working Windows game. Either:

  1. Install it with Steam for Windows inside a Wine wrapper such as Whisky or CrossOver, then choose the folder inside the bottle:
    Whisky: ~/Library/Containers/com.isaacmarovitz.Whisky/Bottles/<bottle>/drive_c/Program Files (x86)/Steam/steamapps/common/Distant Worlds Universe
    CrossOver: ~/Library/Application Support/CrossOver/Bottles/<bottle>/drive_c/Program Files (x86)/Steam/steamapps/common/Distant Worlds Universe
    (Both are found automatically. In the folder picker, ⇧⌘G types a path and ⇧⌘. shows hidden folders such as Library.)
  2. Copy the folder from a Windows PC (in Steam there: right-click the game → Manage → Browse local files): copy the whole Distant Worlds Universe folder over a USB drive or the network to ~/Games/Distant Worlds Universe, which openDWU also finds by itself.
