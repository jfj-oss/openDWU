# Playtest 2026-09-25 — bug list

Read-only playtest of branch `wip/playtest` (base `a496d05`). Nothing in `src/` was changed.

## Setup

- Dev server: `npx vite --port 5191 --strictPort` from `game/`, run with a wrapper config
  (`mergeConfig(vite.config.ts, { cacheDir: <private dir>, server.watch.ignored: node_modules })`).
  **Why:** the first server shared `node_modules/.vite` with the other worktrees' dev servers, because `node_modules` is a
  symlink to `projects/Dwureup/game/node_modules`. The shared optimizer cache was rewritten while the game was booting:
  `504 (Outdated Optimize Dep)` on `node_modules/.vite/deps/browserAll-*.js` →
  `Failed to fetch dynamically imported module`, and the page stayed blank after "Start Game". It also printed
  `page reload src/ui/...` for edits made in *other* worktrees. The wrapper config fixed both; the server did not die after
  that. `scripts/smoke.mjs` spawns vite with the default cacheDir, so it can hit the same 504 while other servers run.
  I noted this but did not change the harness.
- Driver: a persistent playwright-core session (system Chromium, swiftshader, 1920×1080 at DPR 2, so every screenshot is
  3840×2160), controlled over a local HTTP REPL. It logs every console message, `pageerror`, failed request and HTTP ≥ 400.
- Render speed: under machine load (loadavg 17–29), Main View ran at **0.3–2 fps** at 4K, so the sim covered about
  110 game-ms per real second at 4x. This is environmental, not a game bug.
- **Seed 1:** main menu → New Game wizard (every page, seed set to 1, defaults otherwise: 10 AI empires, Expansion
  "Starting") → played from 2150.01.01 to **2150.04.10** (≈100 game days) at 4x. Saved, then loaded twice (from the
  in-game panel and from the main menu).
- **Seed 2:** `?autostart=1&seed=2` (player plus 3 AI) → played from 2150.01.01 to **2150.03.04** (62 game days) at 4x. Saved, loaded from the in-game
  panel, and ran to 2150.03.09. The save/load round trip was exact: same `nowMs`, all 156 galaxy locations, all 809 built
  objects and positions, every empire's money and every habitat owner (hash-compared).
- Screenshots are in `game/shots/pt-*.png` (4K). `shots/` is gitignored, so they are listed here and not committed.

Severity: **crash** (game unusable or frozen) / **wrong data** / **visual** / **polish**.

**Counts:** 19 bugs. 1 crash, 9 wrong data, 4 visual, 5 polish.
**Top 5:** #1 (null `builtObjects` entry freezes the game, even after load), #16 (no ship leaves its home system, so no
contact or expansion in 60–100 days), #2 (wizard offers 3 races), #3 (default empire name " Empire"), #6 (Empires list
shows unmet empires).

## Bugs

### 1. Null entry in `galaxy.builtObjects` freezes the game — also survives save/load  — **crash**
- **Steps:** seed 1, run at 4x with the Main View at System zoom (ships drawn) until a ship or base is torn down.
  It happened at 2150.03.26 (~85 days).
- **What happened:** the `pageerror` below fired, then **everything stopped**: `galaxy.nowMs` stayed frozen, the Pixi
  ticker never scheduled another frame, and no toast or pause appeared. Saving still worked. The save **keeps the null
  hole**, so the loaded game froze again on its first frame at System zoom. At Galaxy/Sector zoom the layer returns early,
  which hides the bug. Harness workaround (to keep testing): splice the nulls out, then run `app.ticker.stop(); start()`.
- **Console:**
  ```
  [pageerror] Cannot read properties of null (reading 'hasBeenDestroyed')
      at BuiltObjectLayer.update (src/render/builtObjectLayer.ts:396:11 served / ~439 source)
      at MainView.update (src/render/mainView.ts:1145:25)
      at TickerListener._fn (src/main.ts:485:8)
  ```
- **Expected:** the C# also leaves null holes (`BuiltObject.2.cs:5522 _Galaxy.BuiltObjects[num15] = null`) and compacts
  them only in `Galaxy.9.cs:2862 RemoveNullBuiltObjects` (habitat removal). The port copies this
  (`src/sim/combat/teardown.ts:381`, and `galaxySave.ts:422` keeps holes on purpose), so every consumer must skip `null`.
- **Likely files:** `src/render/builtObjectLayer.ts:438-439` (`for (const bo of this.galaxy.builtObjects) if (bo.hasBeenDestroyed)`)
  and `:510` (`pick()`: `.filter((b) => !b.hasBeenDestroyed)`). `src/render/overlayLayer.ts:155-156` already has the
  right guard. Also `src/main.ts:~425` (`app.ticker.add(() => { simLoop.tick(...); view.update(); })`): `view.update()`
  runs outside `simLoop.tick`'s try/catch. Any render exception therefore stops the ticker for good, and the player gets
  no "Simulation error — game paused" toast.
- **Shots:** `shots/pt-11-frozen-after-null-builtobject.png`, `shots/pt-16-after-load-system-zoom.png` (frozen again
  after load).

## Works

- Main menu, all 7 wizard pages, seed input, Start Game. The game boots in about 22 s (wizard) or 49 s (autostart)
  under load.
- HUD clock: play/pause button, Pause key, Faster/Slower up to 4x, and the date label follows `galaxy.nowMs`. The game
  menu pauses and Resume unpauses.
- Screens that open by hotkey or top-bar button, show plausible data and close on Escape or a second click: F1
  Galactopedia (tree, 22 race topics with portraits and bonuses, search, related links), F2 Colonies, F5 Diplomacy, F6
  Empire Summary, F7 Research (tabs, queue, tree), F8 Designs (list + detail + components), F9 Build Order, F10
  Construction Yards (row → yard detail), F11 Ships & Bases, F12 Fleets (row selects the fleet), G Galaxy Map (all view
  filters, resource/type dropdowns, click-select, double-click jumps and closes), H Message History, V Empire Comparison
  (Victory / Comparison / Achievements tabs), and the Empires list.
- Zoom: Home (100%), Insert (System), Delete (Sector), End (Galaxy), PageUp/PageDown, Backspace (zoom to selection),
  Ctrl+C (cycle and move view). The layers cross-fade with no hard switch. Planets, moons, orbits, stations and the
  selection ring render at planet/system level.
- Selection: clicking a station or ship (when paused) selects it with owner/design/mission/target/fuel/speed rows.
  C/Shift+C colonies, M military, Y construction, X exploration, F fleets and P space ports cycle correctly.
- Save (game menu → Save Game → name → Save) lists the save with a timestamp. Load from the in-game panel and from the
  main menu both restore date, money, speed/pause and capital, and the loaded state renders. Main Menu → confirm tears
  the view down (0 canvases).
- Game menu Options: volume sliders, UI Scale (90–125%), system-name and region-label toggles.
- No console errors in either seed apart from bug 1 and the environment 504 (Setup). Galactopedia `HEAD` probes show as
  `net::ERR_ABORTED` in playwright's requestfailed hook but return 200 (benign).
